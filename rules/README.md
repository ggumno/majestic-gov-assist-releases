# База правил Majestic GOV Assist

Здесь размещается проверяемый снимок правил для приложения: manifest.json и documents-<sha256>.json. Клиент проверяет размер, SHA-256 и полноту всех серверов перед заменой предыдущего снимка.

Тексты основаны на предоставленных копиях игровых правил и кодексов. Это канал обновления справочника, а не официальный сайт Majestic RP.
